妙手英文标题助手隐私说明

生效日期：2026 年 10 月 23 日。适用于 Microsoft Edge 版妙手英文标题助手。

处理哪些数据

扩展仅在用户主动使用时读取妙手 ERP 当前标题批量编辑页中的货源标识、中文标题、主图地址、标题输入框内容和字符限制，并保存用户审核、生成或人工修改的英文标题工作记录。

模型请求

用户点击“生成”后，扩展将所选商品的中文标题和主图地址发送至用户自行配置并授权的阿里云百炼 Qwen3-VL-Plus 接口，用于生成英文标题。阿里云对这些数据的处理受用户与阿里云之间的服务条款约束。扩展开发者不设接收商品资料的中转服务器，也不添加独立的广告或分析追踪。

本地保存和导出

模型接口地址和标题工作记录保存在当前浏览器配置文件的扩展本地存储中。同一扩展 ID 更新时，这些记录保留，直到用户主动清除或卸载扩展。API 凭据只保存在扩展会话存储中，浏览器重启或扩展更新后可能需要重新输入。用户主动导出的 JSON 工作记录含商品身份和标题，不含 API 凭据；请按业务资料妥善保管。

妙手保存

扩展只在用户点击“填写勾选项草稿”后修改当前妙手页面的对应标题输入框；不会自动点击保存、提交或发布。最终保存由用户手动决定。不同浏览器配置文件之间不会自动共享工作记录或凭据。

用户控制与联系

用户可在插件中导出、导入或清除标题工作记录，也可清除会话凭据。卸载扩展可能删除其本地记录。隐私相关问题可通过 Microsoft Edge 扩展商店页面列出的发布者联系渠道提出。
